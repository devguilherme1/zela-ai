# Zela Aí · Priorização de zeladoria com Programação Dinâmica (Mochila 0/1)
1. Requisitos: Python 3.10+ com `pandas`, `matplotlib` e `pytest` (`pip install pandas matplotlib pytest`).
2. (Opcional) Regerar a base simulada: `python gerar_dados.py` → `dados/ocorrencias_simuladas.csv`.
3. Abrir e executar `priorizacao_zela_ai.ipynb` (Jupyter, VS Code ou Colab): cenário, fonte dos dados, exemplos, comparação e eficiência.
4. Rodar os testes: `python -m pytest -v` · Algoritmo principal: função `mochila_dp` em `priorizacao.py`.
